Privacy Policy

This application, Rclone Personal Backup, is a private, single-user tool.

Data Collection and Usage

The application uses the Google Drive API solely to upload and store files from the user's local computer to the user's own Google Drive account. The application does not collect, store, or share any personal data, analytics, or telemetry with any third parties. All data remains strictly between the user's local machine and their Google account.

AI and Machine Learning

The application does not use Google APIs to generate, create, or process AI-generated Non-Consensual Intimate Imagery (AI NCII) or any other AI-generated content. It is a simple file synchronization tool.
